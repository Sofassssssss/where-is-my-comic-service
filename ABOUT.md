## Интерфейс веб-сервиса

Реализованный сервис представляет собой сайт с двумя страницами:
- Главная страница для поиска комиксов по базе данных
- Админ-панель для управления состоянием базой данных - добавление и удаление записей, получение статистики

На главной странице располагается поле для ввода слов для поиска (в данный момент доступен ввод только на английском), а также 
ячейка для ввода количества комиксов, которое необходимо найти. На любой из выданных комиксов можно нажать и при желании скачать.

Вход в админ-панель осуществляется по следующим данным:

**Username**: admin

**Password**: password

По умолчанию база данных пустая, ее можно заполнить с помощью кнопки Update database на админ-панели.
Также админу доступно получение статистики - Get statistics (количество записей в бд, количество уникальных слов, количество комиксов на сайте xkcd.com) 
и кнопка Clear database для удаления всех записей из бд.
