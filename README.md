# Сервис для поиска комиксов по ключевым словам

Микросервисное веб-приложение для умного поиска комиксов с сайта [xkcd.com](https://xkcd.com) по ключевым словам.
Подробное описание интерфейса, а также демонстрация работы сервиса представлены в файле [ABOUT.md](ABOUT.md).

Проект использует паттерн **Порты и Адаптеры (Hexagonal Architecture)**. 
Для обеспечения высокой релевантности поиска применен алгоритм **BM25**, 
а для точной обработки текстовых запросов применяется стеммер **Snowball**, нормализующий ключевые слова.

## Стек технологий и архитектура

* **Язык:** Go (Golang)
* **Архитектура:** Microservices, Ports and Adapters
* **База данных:** PostgreSQL (реляционная база данных для хранения метаданных комиксов и индексов)
* **Брокер сообщений:** NATS (асинхронное общение между микросервисами)
* **Поисковый движок:** BM25 (ранжирование и поиск) + Snowball (нормализация слов)
* **Контейнеризация:** Docker

## Инструкции по запуску

Управление проектом происходит с помощью `Makefile`. Скрипт автоматически определяет, что установлено в вашей системе (`docker` или `podman`), и использует соответствующий рантайм для запуска контейнеров.

### Предварительные требования
* Установленный Go (версии 1.21+)
* Docker или Podman + Compose
* Make
* Установленный компилятор `protoc` (для работы с gRPC/Protobuf)

### Запуск и остановка сервисов

Запускает весь кластер микросервисов в фоновом режиме (`-d`), останавливая при этом все запущенные контейнеры (если они есть) 
и собирая актуальные образы (`--build`). Запущенный сервис будет доступен по адресу http://localhost:28080.

``` bash
    make up
```
Останавливает и удаляет запущенные контейнеры кластера, сохраняя при этом данные в volume (база данных не удаляется).

``` bash
    make down
```
Полная очистка среды. Останавливает контейнеры и удаляет все volumes (`-v`). Используйте это, если нужно сбросить состояние базы данных до нуля.

``` bash
    make clean
```


### Тестирование

Полный цикл интеграционного/E2E тестирования. Команда сама подготавливает среду: очищает БД (`clean`), 
поднимает кластер (`up`), ждет 10 секунд для инициализации сервисов, запускает тесты (`run-tests`) и 
после завершения снова убирает за собой (`clean`).

``` bash
    make test
```

Запускает Docker-контейнер с тестами (`tests:latest`) в сети хоста. 
Контейнер автоматически удаляется (`--rm`) после завершения работы. Удобно использовать для отладки работы сервисов, 
так как после запуска тестов, удаляется только контейнер с тестами.

``` bash
    make run-tests
```

Запускает unit-тесты для всех модулей в `search-services`. Команда генерирует отчет о покрытии кода (`cover.out`), 
исключая из него сгенерированные файлы (proto), конфигурации, а также все пассивные (вторичные) адаптеры (работа с БД, брокерами сообщений и внешними API). 
Итоговый отчет конвертируется в читаемый HTML-файл (`cover.html`) и сохраняется в корне проекта.

``` bash
    make unit
```

### Разработка и кодогенерация

Запускает статический анализ кода с помощью golangci-lint. Дополнительно включен строгий линтер gocritic.

``` bash
    make lint
```
Запускает компиляцию файлов Protobuf (генерация Go-кода из `.proto` файлов).

``` bash
    make proto
```

Скачивает и устанавливает все необходимые зависимости и инструменты, помогая быстро настроить рабочее окружение.
Также скрипт проверяет наличие системной утилиты `protoc` и выдает ссылку на инструкцию, если она не установлена.

``` bash
    make tools
```
